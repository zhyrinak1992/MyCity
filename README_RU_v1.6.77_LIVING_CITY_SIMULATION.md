# My City v1.6.77 — Живой город и общественная активность

## Изменение блока

Поведение свободных жителей переведено от случайных прогулок по пустым точкам к посещению реально построенных общественных и коммерческих объектов.

- Для выбора активности используются существующие здания города, имеющие рабочую/общественную функцию.
- Житель прокладывает маршрут к входу выбранного объекта средствами существующей пешеходной сети.
- По прибытии житель остаётся на месте на 10–45 игровых минут, затем выбирает следующую активность.
- Факт посещения записывается в индивидуальную историю жителя и публикуется через `GameEventBus`.
- Время пребывания уменьшается по единому игровому минутному часу города.
- При смене фазы расписания текущая активность сбрасывается; фиксированные маршруты домой/на работу сохраняются.
- История посещений ограничена 120 последними записями на жителя.

## Границы реализации

В версии v1.6.78 поверх посещений добавлена связка с реальной розничной покупкой. Диалоги, дружба, семейные визиты, индивидуальные очереди и специальные досуговые заведения остаются открытыми. Фактическая компиляция Unity, Play Mode и iOS build не выполнялись в этой среде.

## Статическая проверка

Скрипт `Tools/Tools_validate_living_city.py` проверяет обязательные точки интеграции, сохранение истории посещений, ограничение журнала, использование общего игрового времени и сохранность фиксированных маршрутов сна/работы.
