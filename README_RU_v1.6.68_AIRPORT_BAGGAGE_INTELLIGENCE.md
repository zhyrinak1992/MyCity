# My City v1.6.68 — интеллектуальная система багажа аэропорта

## Что добавлено

- `AirportBaggageIntelligenceSystem` — отдельный компонент жизненного цикла багажа.
- `AirportBaggageRecord` — запись конкретного чемодана с уникальной биркой, пассажиром, рейсом, направлением и временными отметками.
- Маршрут: принято на регистрации → сортировка → назначено на рейс → загружено → перевозка → выгружено → лента выдачи → получено пассажиром.
- Исключения: задержка, ошибочная сортировка, утеря и последующее восстановление.
- Публичные счётчики по каждому статусу.
- Сохранение состояния в PlayerPrefs и восстановление без повторного создания записей по PassengerId.
- Автоматическое подключение компонента в `MyCityBootstrap`.

## Важные границы текущей реализации

Это логическая симуляция, связанная с индивидуальными пассажирами v1.6.63–v1.6.66. Она не является полноценной физической сортировочной системой: несколько конвейерных линий, сканеры, погрузчики, ручная диспетчеризация, экран поиска по бирке и журнал действий ещё не реализованы. Сценарии задержки/ошибки/утери заданы детерминированными тестовыми правилами, а не статистической моделью аэропорта.

Состояния багажа сохраняются отдельно в PlayerPrefs. Объединение с единым слотом сохранения города остаётся отдельной задачей.

## Проверка

Статически проверены наличие класса, интеграция в Bootstrap, ключевые переходы состояний, сохранение и структура файлов. Unity Editor в этой среде не запускался; компиляция C#, Play Mode, баланс симуляции и производительность на Windows/iPhone не подтверждены.
