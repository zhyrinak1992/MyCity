# My City v1.6.30 — история рейтингов поставщиков

## Реализовано
- Добавлена сохраняемая модель `SupplierRatingSnapshotRecord` и список `WorkplaceRecord.SupplierRatingHistory`.
- В прототипе используется фиксированный экономический месяц длиной 30 игровых дней.
- На границе каждого 30-дневного периода создаётся один снимок по каждому поставщику магазина.
- В расчёт периода попадают только неотменённые принятые поставки с `CompletedDay` внутри периода; качественные возвраты учитываются по `CreatedDay`.
- Снимок сохраняет общий балл, баллы качества/сроков/комплектности, количество завершённых поставок, принятых, дефектных и недостающих единиц.
- При менее чем трёх завершённых поставках снимок помечается предварительным.
- В интерфейсе отображаются до шести последних записей; в сохранении хранится не более 24 периодов.
- Повторное сохранение на одной границе месяца предотвращается полем `LastSupplierRatingSnapshotPeriod`.

## Важные ограничения
- Экономический месяц условно равен 30 игровым дням; календарные месяцы и високосные годы не моделируются.
- Исторические снимки не пересчитываются задним числом после изменения старых поставок или возвратов.
- Сравнение поставщиков остаётся в пределах конкретного магазина.
- Unity Editor/компиляция/Play Mode не запускались в этой среде. Перед интеграцией требуется проверить компиляцию и поведение сохранения в Unity.
