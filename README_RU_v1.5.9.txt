MY CITY UNITY v1.5.9 — МЕЖСКЛАДСКИЕ ПЕРЕВОЗКИ

Основа: v1.5.8.

Добавлено:
- API межскладской перевозки TryDispatchWarehouseTransfer.
- Проверка доступности обоих складов, запасов, свободной вместимости и непрерывного дорожного маршрута.
- Резервирование товара на складе отправления при постановке заявки в очередь.
- Погрузка через FIFO-диспетчеризацию исходного склада.
- После погрузки заявка автоматически переходит в очередь разгрузки склада назначения.
- Фактическое перемещение запасов происходит только после завершения разгрузки.
- Если склад назначения закрыт или не может принять груз, резерв возвращается на склад отправления.
- Состояния этапов и реквизиты перевозки сохраняются в очередях/назначениях доков.
- Схема сохранений повышена до 13; старые записи продолжают загружаться, новые поля инициализируются значениями по умолчанию.

Границы версии:
- Межскладская операция реализована на уровне складской логики и диспетчеризации доков.
- Этот API пока не подключён к отдельной панели назначения межскладского рейса.
- Визуальный грузовик для межскладской перевозки и исполнение его движения по дорожным узлам пока не подключены.
- Нельзя считать Unity-компиляцию или запуск подтверждёнными: Editor в этой итерации не запускался.

Проверки этой итерации:
- Проверен баланс фигурных скобок 23 C#-файлов.
- Проверено наличие route validation, stock reservation, load/unload queue handoff и rollback.
- Проверена целостность ZIP после упаковки.
