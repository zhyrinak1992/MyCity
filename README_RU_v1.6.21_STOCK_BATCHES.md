# My City v1.6.21 — партии товара, сроки годности и FEFO

## Реализовано в исходниках
- Добавлена сохраняемая сущность `StoreStockLotRecord`: SKU, источник-поставка, дата приёмки, дата окончания срока годности, остаток партии и себестоимость единицы.
- При регистрации магазина старые остатки мигрируются в партии, чтобы существующие сохранения не теряли товар.
- При физической приёмке поставки создаётся отдельная партия с привязкой к `StoreDeliveryRecord`.
- Для продаж используется FEFO: первой расходуется партия с ближайшей датой окончания срока годности; при равенстве дат — более ранняя приёмка.
- По наступлении следующего дня после даты годности непроданный, не зарезервированный под возврат остаток списывается из доступного складского количества. Убыток классифицируется в `LastDailyExpiryLoss` и `CumulativeExpiryLoss` без повторного списания денег с кассы.
- Сроки годности прототипные и задаются по категории: продукты 14 дней, косметика 540, одежда 1825, электроника/книги 3650, прочее 365 дней.

## Ограничения
- Сроки годности пока назначаются по категории, а не по индивидуальной маркировке производителя.
- Автоматический FEFO расходует партии по сроку, но возврат поставщику пока не выбирает конкретную исходную партию автоматически.
- Не добавлен отдельный UI-экран карточек партий и журнала списаний.
- Партии склада магазина поддерживаются; партии на региональных складах в этой версии не вводились.

## Проверки
Статическая проверка структуры исходников и ZIP/Excel. Unity Editor, C# compiler и Play Mode недоступны в среде подготовки; сборка и игровые сценарии требуют проверки в Unity 6000.3.29f1.
