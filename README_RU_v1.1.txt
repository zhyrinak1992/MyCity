MY CITY — ПРОТОТИП v1.1
Основа системы занятости и рабочих мест

Изменения:
- Добавлены поля занятости жителя: WorkplaceBuildingId, ProfessionId, MonthlySalary, IsEmployed, DaysWorked.
- Добавлена модель WorkplaceRecord: здание, профессия, штатная вместимость, численность и месячный фонд оплаты труда.
- Добавлен WorkScheduleSystem: регистрация рабочих мест и жителей, назначение/снятие с должности, контроль штатной вместимости, пересчёт фонда оплаты труда.
- Посещаемость рабочего места переключается по городским часам: 09:00–17:00 — at_work, вне этого окна — off_duty.
- Добавлены события EmploymentChanged и WorkAttendanceChanged.
- Магазин в вертикальном срезе теперь описывается как рабочее место с четырьмя штатными местами (модель/данные; интерфейс назначения персонала ещё не подключён).
- У зданий теперь стабильный ID, который не меняется при каждом сохранении.
- Сохранение группирует здания и жителей в сектор и записывает постоянные ID зданий/жителей и список рабочих мест.

Границы текущей реализации:
- WorkScheduleSystem — рабочий слой данных и бизнес-правил; назначение работников из игрового UI и физическое перемещение по маршрутам к рабочему месту пока не реализованы.
- Визуальные ResidentAgent пока не получают автоматические назначения на работу; для этого нужен следующий этап интеграции с интерфейсом и навигацией.
- Зарплата учитывается как месячный фонд оплаты труда, но ещё не списывается из экономики города и не начисляется жителям.
- Загрузка сохранения и восстановление сцены/агентов ещё не реализованы полностью.
- Unity Editor не запускался; сборка и runtime-проверка не подтверждены.

Проверки в исходниках:
- Статическая проверка полей и API занятости.
- Проверка наличия стабильного ID здания в сохранении.
- Проверка сохранения записей жителей и рабочих мест.
- Проверка отсутствия повторной генерации ID здания при сохранении.
