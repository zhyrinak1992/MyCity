MY CITY — v1.5.2: МАРШРУТИЗАЦИЯ ГРУЗОВ ПО ДОРОЖНОЙ СЕТИ

Добавлено:
- RoadNetworkGraph.TryFindPath: детерминированный A* по существующим двунаправленным дорожным рёбрам.
- Соседи и равные оценки сортируются детерминированно; диагональные переходы невозможны, путь состоит только из реальных рёбер графа.
- RoadRoutePlanner.TryBuildRoadPath предоставляет логистике дорожный маршрут.
- Поставщикам назначены узлы доступа к стартовой дорожной сети; производственные площадки имеют RoadNodeX/RoadNodeZ.
- SupplyLogisticsSystem.TryPlaceOrderByRoad рассчитывает маршрут и расстояние по графу. Если связного маршрута нет, заказ не оформляется, деньги и товар не списываются.
- Маршрут сохраняется в заказе и записи грузового автомобиля.
- Старые сохранения получают совместимые узлы поставщиков и пустые коллекции маршрутов.
- Схема сохранения повышена до v7.

Масштаб прототипа:
- Одна клетка дорожного графа считается одним условным километром для расчёта тарифа и срока доставки.
- Поставщики пока представлены логическими узлами, а не построенными зданиями на карте.
- ProductionSiteRecord должен получить координаты дорожного узла, ближайшего к фактическому въезду предприятия; по умолчанию (0,0) — временный центральный узел.

Ограничения:
- Путь вычисляется и сохраняется, но видимое движение 3D-грузовика пока не реализовано.
- Нет дорожных пробок, скоростных ограничений, светофоров, одностороннего движения, закрытий дорог по ЧС и динамического перепланирования.
- Нет физической погрузки/разгрузки, нескольких автомобилей на крупную партию и промежуточных складов.
- Новый API TryPlaceOrderByRoad готов для вызова из диспетчерского UI, но интерфейс заказа пока не подключён.
- Unity Editor не запускался; компиляция и runtime не подтверждены.
