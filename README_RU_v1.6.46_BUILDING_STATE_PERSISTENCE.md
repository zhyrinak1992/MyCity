# My City — v1.6.46 BUILDING STATE PERSISTENCE

## Что изменено

- `PlacedBuilding` теперь хранит фактические `Level` и `Condition` в runtime-модели.
- При восстановлении здания значения читаются из `BuildingRecord`.
- При `SaveCity()` в `BuildingRecord` записываются текущие значения здания вместо принудительных `Level = 1` и `Condition = 1`.
- Для совместимости уровень ограничивается снизу единицей, а техническое состояние — диапазоном 0..1.

## Зачем это нужно

Это обязательная основа для следующих механик: износ зданий, ремонтные проекты, улучшения и развитие инфраструктуры. Без неё сохранение могло бы отменять результат ремонта или модернизации.

## Что пока НЕ реализовано

- Игровое повреждение/износ зданий и визуальный индикатор состояния.
- Очередь ремонтных проектов со сроками и прогрессом.
- Повышение уровня здания с игровыми эффектами.
- Привязка одобренного обращения мэру к реальному ремонтному проекту.
- Отдельная touch-адаптация интерфейса под iPhone.

Эти пункты остаются следующим этапом; текущая версия не должна описываться как уже имеющая полноценную систему ремонтов.

## Проверки

Проверены статически изменённые участки исходников, структура ZIP и открытие Excel. Unity Editor, C# compilation, Play Mode и iOS build в этой среде не запускались. Поэтому финальная проверка поведения сохранения должна быть выполнена в Unity: построить здание → сохранить → перезапустить → загрузить → сохранить повторно → проверить Level/Condition.
