# My City Unity v1.6.16 — ручная приёмка розничных поставок

## Что изменено
- Физически прибывшая машина теперь переходит в статус «Ожидает приёмки» и остаётся у магазина.
- Автоматическое зачисление товара при прибытии отключено: до подтверждения акта остатки магазина не меняются.
- Во вкладке «Закупки» добавлен блок приёмки с полями «Получено», «Повреждено» и «Причина».
- Проверяется диапазон: 0 ≤ получено ≤ заказано; 0 ≤ повреждено ≤ получено.
- После подтверждения введённые значения записываются в существующую модель StoreDeliveryRecord, затем штатная логистика проводит приёмку, недостачу, списание повреждений и возврат переплаты.
- Поставка не принимается повторно: используются существующие IsAccepted, IsShortageRefunded и IsDamageWrittenOff.

## Ограничения и проверки
- Отчёт приёмки доступен после физического прибытия автомобиля.
- Для старых сохранений используются существующие поля модели; новые обязательные поля не добавлялись.
- Статически проверены изменённые участки и архив. Unity Editor / Play Mode в этой среде не запускались.

## Проверить в Unity
1. Открыть проект в Unity 6000.3.29f1.
2. Создать заказ и дождаться статуса «Ожидает приёмки».
3. Проверить полную приёмку 100/100/0.
4. Проверить недостачу 92/100/0.
5. Проверить повреждение 100/100/4.
6. Проверить комбинированный случай 92/100/4.
7. Убедиться, что до нажатия «Принять» остаток магазина не меняется, а после подтверждения проводится ровно один раз.
