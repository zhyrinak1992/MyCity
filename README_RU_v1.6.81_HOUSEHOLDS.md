# My City v1.6.81 — домохозяйства

## Реализовано
- Добавлена сериализуемая запись `HouseholdRecord` и постоянный `HouseholdId` у жителя.
- Домохозяйство формируется по общему `HomeBuildingId`. Жители без назначенного жилья получают отдельную группу, чтобы не объединять незнакомых людей.
- Сохраняется список участников, число взрослых и детей (возрастной порог 18 лет), средние показатели четырёх потребностей и суммарная покупательная способность личных кошельков.
- Личные кошельки остаются раздельными: `CombinedPersonalWallets` — только агрегат для интерфейса/аналитики, не общий счёт и не разрешение списывать деньги другого жителя.
- Снимок домохозяйств сохраняется в `CitySaveData.Households`. При загрузке он пересчитывается из записей жителей, чтобы не доверять устаревшим агрегатам.

## Ограничения
- Совместное проживание не означает родство. Отдельная модель родственных связей пока не реализована.
- Общего семейного банковского счёта, переводов между членами семьи, общего бюджета расходов и семейных решений о покупках пока нет.
- Нет UI управления домохозяйством и проверки в Unity runtime.
- Unity compile, Play Mode и iOS build не выполнялись.
