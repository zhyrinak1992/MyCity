# My City v1.6.26 — классификация дефектов

## Реализовано в исходниках
- Добавлено поле `DefectCategory` в запись партии магазина.
- Добавлено поле `DefectCategory` в запись истории проверки качества.
- Добавлена перегрузка `SetStoreLotQuarantinedUnits` с передачей категории дефекта; прежняя сигнатура сохранена для совместимости вызывающего кода.
- В интерфейсе партии доступны отдельные действия изоляции одной единицы с категориями: «Упаковка», «Срок», «Производство», «Хранение».
- При допуске единицы категория сохраняется в записи истории операции, а при полном снятии карантина текущая категория партии очищается.
- История отображает категорию дефекта рядом с операцией.
- Существующие сохранения совместимы: новые строковые поля могут оставаться пустыми.

## Правила учёта
- Количество карантинных единиц и изменение агрегированного продаваемого остатка по-прежнему рассчитываются прежним методом; классификация не меняет количество товара.
- Категория описывает причину изоляции партии/карантинного остатка; при нескольких разных причинах в одной партии отображается последняя назначенная категория.
- Список категорий пока фиксированный в интерфейсе; пользовательский справочник и аналитика дефектов по поставщикам ещё не реализованы.

## Проверки
- ZIP проверен на целостность.
- Проверен баланс фигурных и круглых скобок в изменённых C# файлах.
- Проверены вызовы новой перегрузки и наличие старой сигнатуры.
- Unity Editor, компиляция проекта и Play Mode не запускались; перед сборкой iPhone требуется проверка в Unity.
