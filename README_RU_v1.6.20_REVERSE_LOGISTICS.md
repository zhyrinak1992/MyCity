
## Дополнение: применение зачёта поставщика
- Накопленный `SupplierCreditBalance` автоматически применяется к следующим заказам у поставщика, если они идут по календарному каналу поставки.
- Зачёт уменьшает фактическое списание с операционного баланса; применённая сумма сохраняется в `StoreDeliveryRecord.SupplierCreditApplied`.
- Автоматическое пополнение учитывает баланс магазина вместе с доступным зачётом. Если зачёт применён, заказ оформляется по поставщику, а не как физическая отгрузка с внутреннего склада: кредит поставщика нельзя расходовать на внутренний склад.
- Для физической складской отгрузки по-прежнему требуется полная оплата внутреннего заказа.
