# My City v1.6.38 — единый журнал финансовых операций поставщиков

## Новые блоки

### 1. Журнал расчётов с поставщиками
- Каждая предоплата заказа записывается в финансовую историю поставщика.
- При физической приёмке возврат стоимости недостающих/бракованных единиц записывается отдельной операцией сторно.
- При урегулировании признанной претензии дополнительная компенсация фиксируется отдельной операцией.
- Запись содержит ID, тип, сумму, игровой день, ID заказа, ID претензии и пояснение.
- История ограничена последними 500 операциями на поставщика и сохраняется внутри SupplierRecord вместе с городским сохранением.

### 2. Сверка оборотов в интерфейсе
- Для каждого поставщика отображаются накопленные суммы: оплачено по заказам, возвращено за брак/недостачу, выплачено дополнительной компенсацией.
- Это контрольные обороты по сохранённым операциям, а не расчёт текущей задолженности: отдельный баланс/лимит кредитования поставщика в модели отсутствует.

### 3. Сохранённые механики
- Претензионная работа, денежное урегулирование, переговоры и история договоров из v1.6.36–v1.6.37 сохранены.
- Сторно товара не дублируется выплатой претензии; дополнительная компенсация учитывается отдельно.

## Ограничения
- Пока нет отдельного баланса поставщика, двусторонних проводок дебет/кредит, автоматического взаимозачёта, просроченной кредиторской задолженности и банковских выписок.
- Журнал операций — внутренний игровой реестр, не полноценная бухгалтерская система.
- Unity Editor, C# compiler и Play Mode не запускались; проведены статические проверки и проверка архива/Excel.
