MY CITY — ПРОТОТИП v0.9
Расписания жителей подключены к единому игровому времени

Изменения относительно v0.8:
- Переходы между фазами расписания вызываются событиями GameClock.OnTick.
- Один OnTick соответствует одной игровой минуте; счётчик уменьшается ровно на одну минуту.
- Базовая длительность фазы — 360 игровых минут (6 часов); цикл содержит четыре фазы.
- При переходе фазы житель получает новую точку назначения, публикуется CitizenStateChanged с фактическим номером тика.
- Агентам вертикального среза добавлены счётчики фазы расписания.
- CitizenSimulationSystem надёжно подписывается на GameClock даже при позднем создании часов.

Проверки: статическая проверка исходников и ссылок. Unity Editor в среде сборки отсутствует; компиляция и запуск не подтверждены.

Ограничения: четыре фазы по шесть часов — временная базовая модель. Передвижение пока является упрощённым блужданием, а не маршрутом дом—работа—магазин. Полное сохранение записей всех жителей ещё не интегрировано.
