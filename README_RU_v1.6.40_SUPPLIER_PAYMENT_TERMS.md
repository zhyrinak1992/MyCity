# My City v1.6.40 — условия оплаты поставщикам

Основа: v1.6.39. Добавлены договорные параметры оплаты: доля предоплаты (0–1000‰), срок отсрочки в игровых днях и кредитный лимит поставщика.

При размещении заказа списывается только предоплата. Остаток фиксируется как задолженность с датой платежа. Проверка кредитного лимита учитывает уже открытые задолженности. Автоматический выбор поставщика также учитывает размер предоплаты и доступный кредитный лимит.

Добавлен API `TrySetSupplierPaymentTerms` для настройки условий и `TryPaySupplierOrderBalance` для полного/частичного погашения долга. Все операции записываются в финансовую историю. Сводка рассчитывает задолженность как начисления минус погашения.

Старые сохранения нормализуются к полной предоплате, чтобы не менять прежнее поведение.

Ограничения: интерфейс настройки условий, автоматическое списание при наступлении срока, штрафы и экран просроченной задолженности пока не реализованы. Unity Editor/компиляция/Play Mode не запускались. Выполнены только статические проверки структуры.
