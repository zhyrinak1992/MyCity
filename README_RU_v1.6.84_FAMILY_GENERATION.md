# My City v1.6.84 — генерация семейных домохозяйств

## Изменения
- При первичном заселении нового жилого здания жители получают один из детерминированных сценариев домохозяйства: супружеская пара (до трёх детей), один родитель (до трёх детей) или взрослые соседи без родственных связей.
- В крупных жилых зданиях семейная группа ограничена пятью участниками для пары или четырьмя для одного родителя; остальные жильцы остаются взрослыми соседями без автоматически созданного родства.
- Сценарий выбирается по стабильному идентификатору здания, а не через Unity Random.
- Семейные связи создаются только как явные записи через `CitizenRelationshipSystem`; совместное проживание само по себе не объявляется родством.
- Новые жители регистрируются в системе отношений до создания супружеских и родительских связей.
- Существующие сохранения не перегенерируются: генератор вызывается только при первичном заселении нового жилого здания.
- Связи сохраняются и восстанавливаются через существующий `CitySaveData.CitizenRelationships`.

## Ограничения
- Это начальная генерация состава домохозяйств при заселении, а не полноценная симуляция браков, рождения детей, взросления и переезда.
- Возраст хранится в данных, но индивидуальная возрастная внешность персонажей пока не реализована.
- Семейные сценарии упрощены и требуют последующей балансировки.
