# My City v1.6.85 — Семейный интерфейс

Дата: 26.11.2026  
Мастер-ТЗ: v2.140 (продолжение v2.139)

## Что добавлено

- В игровом интерфейсе добавлена панель «Семья · родственные связи».
- Для выбранного жителя отображаются возраст, супруг/супруга, родители и дети на основании явных активных записей `CitizenRelationshipSystem`.
- Отдельно показываются люди, проживающие с выбранным жителем в одном домохозяйстве. Они явно не обозначаются родственниками.
- Список членов домохозяйства берётся из `HouseholdSystem`; семейные связи — из сохраняемой модели `CitizenRelationshipRecord`.
- Добавлены переключение выбранного жителя, прокрутка и закрытие панели.
- Существующие данные о родстве не дублируются и не выводятся из общего адреса.

## Границы версии

- Не добавлялись усыновление, опека, редактирование родства, автоматические рождения, взросление, браки или переезды.
- Не добавлялись семейные счета и общие расходы: пункт FAM-009 остаётся следующим этапом после закрытия отображения семейных связей.
- Визуальная возрастная модель персонажей не менялась.

## Проверки

Запустить из корня проекта:

```bash
python Tools/validate_v1_6_85_release.py
```

Проверки статические: они проверяют ранее созданные семейные связи, генерацию семей, наличие и подключение панели семейного интерфейса и баланс фигурных скобок C#.

Unity Editor compilation, Play Mode, фактическое сохранение/загрузка в Unity и iOS build в этой среде не выполнялись. Поэтому версия не заявляется как runtime-проверенная.
