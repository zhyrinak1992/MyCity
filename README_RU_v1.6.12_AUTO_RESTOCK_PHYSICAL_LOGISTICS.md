# My City v1.6.12 — автоматическое пополнение через физическую логистику

## Изменения

- Автоматическое пополнение ассортимента магазина теперь сначала пытается создать физический заказ со склада.
- Для автоматического заказа используется тот же механизм, что и для ручного: выбор склада по свободному запасу и дорожному маршруту, резервирование товара, подбор грузовика и очередь погрузки.
- При успешной диспетчеризации заказ получает внутреннего отправителя и `ArrivalDay = int.MaxValue`; календарная приёмка поставщика не может добавить этот товар повторно.
- Если физическую диспетчеризацию нельзя завершить (нет запаса, маршрута, машины или склада), заказ остаётся обычной поставкой внешнего поставщика с прежним сроком доставки.
- Стоимость закупки учитывается в тех же дневных расходах магазина; стоимость фрахта продолжает капитализироваться при физической приёмке.

## Проверки и ограничения

- Выполнена статическая проверка изменённого исходника и структуры архива.
- Unity Editor в рабочей среде отсутствует; компиляция и Play Mode не подтверждены.
- Автоматическое пополнение не гарантирует физическую доставку: при отсутствии доступного складского ресурса используется совместимый календарный канал поставщика.
- Отмена уже отправленного рейса, недостачи и повреждения груза остаются отдельными следующими задачами.
