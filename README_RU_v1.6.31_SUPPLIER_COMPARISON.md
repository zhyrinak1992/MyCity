# My City v1.6.31 — сравнение поставщиков и динамика рейтинга

## Изменения
- На вкладке «Возвраты» добавлен блок «Сравнение поставщиков · последний период».
- Для каждого поставщика выбирается последняя сохранённая оценка и ближайшая предыдущая оценка того же SupplierId.
- Показывается текущий балл из 100, изменение в пунктах относительно предыдущего периода, номер периода и две составляющие оценки: качество и своевременность.
- Добавлена горизонтальная шкала текущего балла (0–100).
- Если предыдущего снимка нет, поставщик помечается как новый в истории.
- Используются только сохранённые снимки; новые расчёты рейтинга и правила формирования снимков не менялись.

## Ограничения
- Сравнение доступно после появления сохранённых периодических снимков.
- Период остаётся условным 30-дневным игровым месяцем из v1.6.30.
- Это сравнение истории конкретного торгового объекта, не сводный рейтинг по всему городу.
- История хранит максимум 24 периода; на экране отображаются все поставщики, для которых есть снимки.
- Unity Editor, компиляция и Play Mode в этой среде не запускались.
