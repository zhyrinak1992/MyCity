# My City v1.6.67 — iOS Build Preparation

Версия подготовлена для первого iPhone-билда. Игровые системы v1.6.66 сохранены; добавлены Unity Editor-инструменты для создания стартовой сцены, базовой конфигурации iOS и экспорта Xcode-проекта.

**Это подготовка к сборке, а не готовый IPA.** Для получения IPA требуется Xcode на macOS. При работе только на Windows можно использовать Unity Build Automation или другой облачный Mac-сервис.

Подробная пошаговая инструкция: `IOS_BUILD_PLAN_RU.md`.

В Unity 6000.3.29f1 после открытия проекта запустить `My City > iOS > 1 - Prepare iPhone project`. Затем проверить Console и подключить проект к Unity Build Automation.
