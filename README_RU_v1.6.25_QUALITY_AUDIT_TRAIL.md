# My City v1.6.25 — журнал проверок качества

## Реализовано
- Добавлена сериализуемая запись `StoreQualityInspectionRecord`.
- В `WorkplaceRecord` добавлена история `QualityInspectionHistory`.
- Каждое успешное изменение количества карантинных единиц создаёт отдельную запись: партия, товар, игровой день, прежнее и новое количество, число изменённых единиц, действие («Изоляция» / «Допуск») и причина.
- История сохраняется вместе с `WorkplaceRecord` штатным механизмом сохранения города.
- В интерфейсе магазина показываются последние восемь проверок качества с причиной.
- Для старых сохранений список истории лениво создаётся при первой успешной операции; отсутствие списка не мешает загрузке.

## Сохранённые правила
- Изменение карантина по-прежнему корректирует агрегированный продаваемый остаток только на разницу между старым и новым количеством.
- Нельзя изолировать количество, уже зарезервированное под возврат поставщику.
- История фиксирует только успешно выполненные операции; неуспешные попытки не создают ложных записей.

## Проверки
- Архив ZIP проверен на целостность.
- Проверены баланс фигурных и круглых скобок в трёх изменённых C# файлах.
- Проверено наличие новых полей и всех мест записи/отображения истории.
- Unity Editor, компиляция проекта и Play Mode в этой среде не запускались. Требуется проверка в Unity перед сборкой для iPhone.
