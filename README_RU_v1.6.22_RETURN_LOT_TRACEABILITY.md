# My City v1.6.22 — связь возвратов с партиями

## Изменения
- Возврат резервирует конкретные партии, а не только общий SKU-остаток.
- Партии выбираются по FEFO (сначала ближайший срок годности); для причины «Истёк срок годности» доступны только партии, срок которых уже прошёл.
- В заявке сохраняется список `LotId` и количество из каждой партии.
- При отмене заявки резервы освобождаются; при передаче перевозчику списываются именно закреплённые партии.
- Сумма возврата рассчитывается по фактической себестоимости выбранных партий, а не усреднённой цене всего SKU.
- Просроченные количества, зарезервированные под возврат, не списываются повторно автоматическим процессом просрочки.
- На вкладке «Возвраты» отображается реестр партий: остаток, резерв, срок годности, статус и себестоимость.

## Ограничения
- Подтверждение возврата поставщиком пока остаётся ручным действием игрока после прибытия в распределительный узел.
- Причина «Брак» пока не поддерживает отдельную фиксацию повреждения внутри партии до оформления возврата.
- Unity Editor/Play Mode и компиляция C# в среде подготовки недоступны; требуется проверка в Unity 6000.3.29f1.
