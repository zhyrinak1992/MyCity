# My City v1.6.13 — отмена магазинных физических поставок

## Реализовано

- Добавлен `WarehouseStorageSystem.TryCancelStoreOrder(...)`.
- Заказ, который ещё ожидает погрузки или обслуживается в доке, удаляется из очереди/активного назначения; резерв снимается, грузовик освобождается.
- Если товар уже погружен, отмена не возвращает его на склад мгновенно: рейс разворачивается и физически возвращается по пройденному участку дорожного маршрута.
- После возвращения груз восстанавливается на исходном складе. Если склад временно не может принять груз, возврат остаётся активным и повторяется на следующих игровых минутах.
- Добавлен `CityEconomySystem.TryCancelStoreOrder(buildingId, orderId, out error)` как точка вызова для будущей панели диспетчеризации.
- Стоимость товара возвращается на баланс магазина ровно один раз — сразу при отмене до погрузки или после фактического возврата груза.
- Расходы предприятия и общий показатель бизнес-затрат корректируются при возврате оплаты.
- Для отменённого загруженного рейса учитывается фактически пройденная часть маршрута туда и обратно; эксплуатационные расходы автопарка отражаются через штатное событие списания из городского бюджета.
- Добавлен сохраняемый флаг `IsRefunded` для защиты от повторного возврата денег после загрузки сохранения.

## Ограничения

- Пользовательский интерфейс кнопки отмены и журнал причин отмены пока не добавлены; API готов для подключения панели диспетчеризации.
- Недостачи и повреждения груза, страхование, штрафы и частичная приёмка остаются следующими этапами.
- Unity Editor в среде сборки отсутствует. Статические проверки исходников и целостности ZIP не заменяют компиляцию Unity и проверку Play Mode.
