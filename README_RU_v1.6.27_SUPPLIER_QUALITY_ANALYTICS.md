# My City v1.6.27 — аналитика качества поставщиков

## Реализовано
- На вкладке «Возвраты» добавлен сводный блок аналитики по текущему торговому объекту.
- Считает количество возвращённых единиц и сумму возвратов по незакрытым отменой записям.
- Отдельно показывает количество единиц в возвратах по качественным причинам (брак и истёкший срок годности).
- Группирует возвращённые единицы по отображаемому имени поставщика.
- Суммирует количество единиц, направленных в карантин, по категориям дефектов на основании журнала проверок.
- Данные вычисляются из уже сохраняемых SupplierReturns и QualityInspectionHistory; новая схема сохранений не требуется.

## Методика и ограничения
- Аналитика локальна для выбранного торгового объекта, а не консолидирована по всему городу.
- Показатель качества — абсолютные количества и суммы, не процент брака: достоверный знаменатель поставок в текущей модели не гарантирован для всех legacy-записей.
- Группировка поставщиков использует сохранённое отображаемое имя. Если имя отсутствует, запись попадает в «Поставщик не указан».
- Категории дефектов суммируются по операциям «Изоляция» из журнала; повторная изоляция одной и той же единицы в разные дни может отражаться как несколько событий/единиц. Это показатель объёма зарегистрированных изоляций, а не уникальных физических изделий.
