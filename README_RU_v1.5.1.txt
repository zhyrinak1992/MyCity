MY CITY — v1.5.1: УЧЁТ ГРУЗОВОГО ТРАНСПОРТА

Добавлено:
- CargoVehicleRecord: отдельная запись транспортного средства на каждый заказ.
- Грузовой автомобиль имеет ID, тип, грузоподъёмность, загруженный объём, дистанцию, даты отправки/прибытия и статус.
- Заказ ограничен грузоподъёмностью одной машины: 8 000 условных грузовых единиц.
- В стоимость закупки включается расчётная стоимость перевозки: 18 ₽ за км.
- Срок доставки зависит от дистанции: минимум 1 игровой день, далее +1 день на каждые полные 250 км.
- При приёмке поставки автомобиль помечается как доставленный, груз снимается.
- Автомобили и их связь с заказами сохраняются; старые заказы без VehicleId получают совместимую запись при загрузке.
- Схема сохранения повышена до v6.

Честные ограничения:
- Это пока логистическая симуляция рейса и учёт автопарка, а не видимая 3D-машина.
- Фактический маршрут по RoadNetworkGraph, дорожные пробки, погрузка/разгрузка по времени, несколько машин в одном рейсе,
  склады-перевалочные узлы, водительские смены и обслуживание автопарка ещё не реализованы.
- Текущий API заказа принимает расчётную дистанцию маршрута; UI диспетчеризации ещё нет.
- Unity Editor не запускался: компиляция и runtime не подтверждены.
