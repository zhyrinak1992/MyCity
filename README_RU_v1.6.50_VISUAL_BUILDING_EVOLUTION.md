# My City — v1.6.50 VISUAL BUILDING EVOLUTION

## Что изменено
- Внешний вид размещённого здания теперь зависит от сохранённого уровня модернизации 1–15.
- Уровни 2–5 добавляют архитектурные детали фасада и входную группу.
- Уровни 6–10 добавляют надстройку на крыше и инженерное/энергетическое оборудование.
- Уровни 11–15 добавляют элементы здания-доминанты, угловую подсветку, озеленение и завершающий элемент крыши.
- Визуальные элементы создаются при загрузке здания и обновляются после модернизации; повторное повышение уровня не должно накапливать старые декоративные объекты.
- Игровой footprint и навигационные точки здания не меняются.

## Ограничения
- Это процедурные 3D-детали из примитивов Unity, а не финальные художественные модели/уникальные prefab для каждого типа здания.
- Архитектурные элементы общие для типов зданий; дальнейшая работа должна добавить отдельные визуальные профили для жилья, магазинов, складов и производств.
- На уровнях 2–15 меняется силуэт и детализация, но не создаются полноценные дополнительные этажи с пересчётом физической высоты здания.
- Unity Editor compilation, Play Mode и iOS build не запускались.

## Проверки
Статически проверены вызовы визуальной реконструкции при создании/загрузке и модернизации, уровневые пороги, отсутствие дублирования контейнера Upgrade Visuals, баланс скобок и целостность ZIP.
