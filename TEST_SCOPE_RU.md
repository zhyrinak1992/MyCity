# Реестр готовности тестовой версии

| Контур | Состояние исходного проекта | Проверка в Unity |
|---|---|---|
| Поставщик → производство (физический рейс) | Реализован | Требуется |
| Складские остатки и средневзвешенная стоимость | Реализованы | Требуется |
| Производственная себестоимость выпуска | Реализована | Требуется |
| Склад → склад (физический рейс, доки, фрахт) | Реализован | Требуется |
| Производство → склад (операции передачи запасов) | Есть API передачи | Требуется |
| Автоматическое снабжение производства со склада | Не подтверждено как автоматический цикл | Требуется разработка/проверка |
| Поставщик → склад сырья | Не реализован как отдельный физический маршрут | Требуется разработка |
| Склад готовой продукции → магазин (физический рейс) | Не реализован | Требуется разработка |
| Продажи и списание COGS по фактической себестоимости | Розничная продажа есть; согласование COGS требует доработки | Требуется |
| Единый консолидированный P&L/денежный поток | Не реализован в полном виде | Требуется разработка |

**Критерий сквозной готовности:** один товарный поток должен пройти все звенья, а остатки, резервы, деньги, себестоимость и статусы рейсов должны совпасть до и после сохранения/загрузки. До этого нельзя маркировать цепочку как полностью интегрированную.
