# My City — v1.6.41: календарь платежей поставщикам

## Основа
Версия создана поверх v1.6.40. Существующие системы, данные и предыдущая документация сохранены.

## Добавлено
- Реестр открытых платежей поставщикам с сортировкой по сроку оплаты.
- Отображение основного долга, начисленного штрафа, общей суммы и дней просрочки.
- Настраиваемые параметры штрафа через API: дневная ставка 0–100‰ и предел 0–1000‰ от первоначальной отсроченной суммы.
- Ежедневное начисление штрафа не чаще одного раза за игровой день и с ограничением максимальной суммы.
- Раздельные финансовые записи начисления и погашения штрафа.
- При погашении сумма сначала направляется на штраф, затем на основной долг.
- Уведомление за два игровых дня до срока и уведомление при переходе в просрочку.
- В интерфейсе договоров добавлен календарь и кнопка полного погашения заказа.
- Обновлено мастер-ТЗ до v2.93, добавлен лист «Календарь платежей».

## Важные правила
- Автоматическое списание средств в дату платежа не включено. Оно требует отдельного решения об автоплатеже и порядке приоритетов денежных средств; игра не должна неожиданно списывать средства без явно заданного правила.
- Частичное погашение доступно через существующий API `TryPaySupplierOrderBalance`; текущая кнопка интерфейса выполняет полное погашение выбранного заказа.
- Штрафы являются отдельным обязательством и не увеличивают первоначальный основной долг заказа.
- Старые сохранения получают безопасные значения параметров штрафа через `Normalize`.

## Новые API
- `TrySetSupplierLateFeeTerms(supplierId, dailyPermille, maxPermille, out error)`
- `GetSupplierPaymentSchedule(supplierId, destination)`
- `GetAllSupplierPaymentSchedule(destination)`
- `TryPaySupplierOrderBalance(...)` расширен учётом штрафов и приоритетом их погашения.
