# My City — тестовый проект для Windows

Версия исходного проекта: **v1.6.7 TEST** (основа v1.6.6). Это Unity-проект, а не готовый `.exe`.

## Требуемая среда
- Windows 10/11, 64-bit.
- Unity Hub.
- **Unity Editor 6000.3.29f1** — именно эта версия указана в `ProjectSettings/ProjectVersion.txt`.

## Как открыть
1. Распакуйте архив в обычную папку, например `C:\\Projects\\MyCity_Unity_v1.6.7_TEST`.
2. Запустите Unity Hub → **Add** → **Add project from disk**.
3. Выберите папку `MyCity_Unity_v1.6.7_TEST` (внутри должны быть `Assets`, `Packages`, `ProjectSettings`).
4. Откройте проект указанной версией Unity. Дождитесь импорта Assets.
5. В исходном архиве нет готового файла сцены. Создайте пустую сцену: File → New Scene → Basic (Built-in) или Empty, затем сохраните её как `Assets/Scenes/MyCity_Test.unity` (создайте папку `Scenes`, если её нет).
6. Нажмите Play. Компонент `MyCityBootstrap` автоматически создаётся через `RuntimeInitializeOnLoadMethod` после загрузки сцены и формирует тестовый мир.

## Что уже присутствует в прототипе
- жители, расписания и рабочие места;
- торговые предприятия и ассортимент;
- производственные площадки и рецепты;
- поставщики и физические грузовые рейсы поставщик → производство;
- склады, доки и физические межскладские перевозки;
- автопарк и расчёт фрахта;
- учёт средневзвешенной себестоимости сырья и выпуска;
- сохранение данных города.

## Что НЕ следует считать готовым
- физическая доставка склад → магазин ещё не интегрирована в общий грузовой автопарк;
- розничное пополнение пока использует логические поставки по сроку доставки;
- нет подтверждённой сквозной автоматизации всей цепочки «поставщик → склад сырья → производство → склад готовой продукции → магазин → покупатель»;
- проект не компилировался и не запускался в Unity Editor в этой среде. Этот архив — кандидат для первого локального запуска и проверки, а не подтверждённая сборка.

## Первый тест на компьютере
1. Открытие проекта без ошибок импорта.
2. Отсутствие красных ошибок в Console после загрузки сцены.
3. Запуск Play Mode.
4. Проверка создания/загрузки города и сохранения.
5. Проверка производства, склада и грузового рейса по отдельности.
6. Сохраните Console (ошибки + предупреждения) и пришлите скриншот, если что-либо не запускается.

Не удаляйте исходный архив и старые сохранения до успешного теста.
