# My City — v1.6.49 FIFTEEN LEVEL UPGRADES

## Что изменено
- Максимальный уровень модернизации увеличен с 3 до 15.
- Существующие сохранения уровней 1–3 совместимы; значения при загрузке ограничиваются диапазоном 1–15.
- Жилые здания получают +10% к базовой вместимости за каждый уровень выше первого. Эффект рассчитывается от BaseCapacity по формуле 1.10^(уровень−1), поэтому при загрузке бонус не накапливается повторно.
- Рабочие здания получают одно дополнительное место для сотрудника за каждый новый уровень; значение синхронизируется с WorkplaceRecord.
- Стоимость второго уровня сохраняет прежнюю ставку 45% от базовой стоимости. Для перехода на третий уровень сохраняется прежняя ставка 70%; начиная со следующего перехода ставка растёт на 18 процентных пунктов за уровень: это делает поздние этапы заметно дороже, но не вводит экспоненциальный скачок.
- Панель показывает уровень из 15, текущую стоимость следующего шага и доступность улучшения.
- Расходы продолжают записываться в финансовый журнал с уникальным ID здания и целевого уровня.

## Ограничения
- Визуальная модель здания пока не меняется при повышении уровня.
- Для типов зданий без подключённой характеристики уровня пока сохраняется сам уровень развития, но отдельный производственный бонус ещё не реализован.
- Новые жилые места становятся доступной вместимостью; автоматическое заселение не выполняется.
- Unity Editor compilation, Play Mode и iOS build не запускались.

## Проверки
Статически проверяются диапазон 1–15, загрузка старых уровней, формулы стоимости/вместимости, ограничение максимума, обновление UI и финансовая запись. Архив проверяется на целостность.
