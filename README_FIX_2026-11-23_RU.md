Исправление компиляционных ошибок по скриншоту Unity Console от 23.11.2026

Исправлено:
1. SupplyOrderRecord: добавлены CurrentPathIndex, SegmentProgress и IsReturning — состояние движения грузового заказа теперь соответствует инициализации в SupplyLogisticsSystem.
2. DroneThreatSystem: добавлено публичное свойство LastProcessedDay для сохранения дня последней обработки.
3. MyCityBootstrap.BuildAt: объявление workplace перенесено до первого использования при создании складов.

Предупреждения CS0618 (устаревший FindObjectOfType) и CS0067 (событие пока не используется) не блокируют компиляцию и в этой исправительной сборке не менялись.

Проверка в этой среде: сверены объявления и все места использования исправленных членов; Unity Editor и C# компилятор Unity здесь недоступны. Поэтому это исправление по диагностике, но окончательное подтверждение — после повторного импорта/компиляции проекта в Unity на компьютере пользователя.
