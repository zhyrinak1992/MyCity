MY CITY — ПРОТОТИП v1.3.1

Изменение относительно v1.3:
- RoadRoutePlanner переведён с жёстко заданного Manhattan-прохода на алгоритм A*.
- Маршрут строится по явному графу узлов и рёбер текущей ортогональной уличной решётки.
- Сохранён детерминированный порядок соседей для воспроизводимости маршрутов одинаковой стоимости.
- Добавлена проверка допустимости узлов/рёбер и безопасный fallback, если путь не найден.
- Публичный интерфейс Build(Vector3, Vector3) сохранён: интеграция с MyCityBootstrap не требует ручного объединения файлов.

Ограничения:
- Текущая сеть дорог в вертикальном срезе — регулярная полностью связанная решётка. A* пока не учитывает реальные построенные/закрытые сегменты, тротуары как отдельные рёбра, переходы, препятствия, пробки и транспорт.
- Соединители от здания до ближайшего узла пока прямые; точку входа здания и безопасную пешеходную сторону участка нужно добавить вместе с графом участков.
- Unity Editor не запускался в среде подготовки. Исходники проверяются статически; компиляция и игровой запуск не подтверждены.

Проект: Unity 6.3.29f1 (версия проекта сохранена из исходного архива).
