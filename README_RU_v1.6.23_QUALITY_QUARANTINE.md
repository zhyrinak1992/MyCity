# My City v1.6.23 — контроль качества и карантин партий

## Реализовано
- В `StoreStockLotRecord` добавлены признаки карантина, день проверки и причина.
- Карантин партии исключает её количество из продаваемого агрегированного остатка магазина.
- FEFO-продажа и автоматическое списание просрочки пропускают партии в карантине.
- Партии можно помещать в карантин и возвращать в доступный остаток из экрана «Возвраты».
- Для возврата с причиной «Брак» выбираются только партии в карантине; финансовая стоимость считается по себестоимости этих партий.
- При передаче бракованной партии не происходит повторного вычитания из продаваемого остатка: карантинные единицы уже исключены при помещении в карантин.
- Для обычных возвратов сохранена проверка и корректировка агрегированного остатка и резерва.

## Ограничения
- Карантин применяется целой партией, а не отдельными единицами внутри партии.
- Ручное решение о допуске/карантине пока не имеет отдельной роли сотрудника или многоступенчатого согласования.
- Нет лабораторных параметров, фотофиксации и классификатора дефектов.
- Не выполнены компиляция и Play Mode в Unity Editor; требуется проверка в Unity 6000.3.29f1.
