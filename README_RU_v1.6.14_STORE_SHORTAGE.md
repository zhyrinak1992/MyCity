# My City v1.6.14 — учёт недостачи при физической розничной доставке

## Реализовано в исходниках

- В `StoreDeliveryRecord` добавлены сохраняемые поля фактической приёмки: `HasReportedReceivedUnits`, `ReportedReceivedUnits`, `AcceptedUnits`, `ShortUnits`, `IsShortageRefunded` и `ReceiptStatus`. Отдельный флаг `HasReportedReceivedUnits` сохраняет совместимость со старыми сохранениями: если фактическое количество ещё не фиксировалось, по умолчанию считается, что доставлено всё количество.
- В `CityEconomySystem.TryReportStoreShipmentReceivedUnits(...)` добавлен API фиксации фактически пересчитанного количества. Метод принимает значение от 0 до количества в накладной, не позволяет менять уже зафиксированное количество и не принимает отменённые/закрытые/нефизические заказы.
- `WarehouseStorageSystem.AcceptStoreShipment(...)` добавляет в магазин только фактически принятое количество. Недостающие единицы не появляются в запасах.
- Для недостачи рассчитывается пропорциональный возврат стоимости отсутствующего товара. Возврат защищён сохраняемым флагом `IsShortageRefunded`; повторная обработка не начисляет деньги второй раз.
- В записи заказа сохраняются принятое количество, недостача и результат приёмки; статус различает полную приёмку и приёмку с недостачей.
- Полная поставка без зарегистрированной недостачи сохраняет прежнее поведение. Старые сохранения не требуют ручного заполнения новых полей.

## Пример сценария

Накладная: 100 ед.; фактически пересчитано: 92 ед. После приёмки магазин получает 92 ед., `ShortUnits = 8`, а стоимость 8 отсутствующих единиц возвращается на баланс предприятия один раз.

## Ограничения и проверки

- API фиксации фактического количества готов для подключения к панели приёмки; отдельный экран пересчёта/подтверждения ещё не добавлен.
- Повреждение груза, причины недостачи, претензионная работа, страхование и штрафы не входят в этот инкремент.
- Выполнены статические проверки изменённых исходников и структуры проекта. Unity Editor в рабочей среде отсутствует: компиляция Unity и Play Mode не подтверждены.
