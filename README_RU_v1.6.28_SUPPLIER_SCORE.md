# My City v1.6.28 — рейтинг поставщиков

## Реализовано
- На вкладке «Возвраты» добавлен рейтинг поставщиков по завершённым и принятым поставкам.
- Итоговая оценка 0–100 рассчитывается по трём компонентам: качество — 50%, своевременность — 25%, комплектность — 25%.
- Качество учитывает повреждения при приёмке и позднее оформленные качественные возвраты.
- Своевременность определяется сравнением фактического `CompletedDay` с плановым `ArrivalDay`.
- Комплектность рассчитывается по недостаче относительно заказанного количества.
- Для каждого поставщика выводятся количество поставок, принятое количество, дефекты и недостача.
- Рейтинг рассчитывается из существующих записей магазина и не требует миграции сохранений.

## Методика и ограничения
- В расчёт входят только записи `IsAccepted == true` и не отменённые поставки.
- Поставки без фактического/планового дня не считаются своевременными.
- Качественные возвраты учитываются как дополнительные инциденты качества. Это может относить поздно выявленный дефект к поставщику, указанному в возврате.
- При отсутствии истории приёмок рейтинг не отображается.
- Это локальный рейтинг конкретного магазина, а не глобальный рейтинг сети поставщиков.
- Пока нет нормализации по категориям товаров, весу/стоимости груза и объёму выборки; при малом числе поставок оценка предварительная.

## Проверки
Проведены ZIP integrity check, структурная проверка Excel и базовая проверка баланса скобок изменённого C# файла. Unity Editor/компилятор и Play Mode не запускались; компиляция и игровое поведение требуют проверки в Unity.
