# My City v1.6.32 — автоматический выбор поставщика по полной стоимости

## Реализовано
- В `SupplyLogisticsSystem` добавлен публичный метод `TryPlaceBestValueOrderByRoad` для автоматического выбора поставщика производственного сырья.
- В кандидаты попадают только работающие поставщики, у которых есть требуемый товар и достаточный остаток.
- Для каждого кандидата проверяется непрерывный маршрут по существующей дорожной сети до производственной площадки.
- Сравнивается полная стоимость закупки: цена товара × количество + транспортный тариф (18 ₽ за км маршрута).
- Выбирается предложение с минимальной полной стоимостью, которое предприятие может оплатить.
- При равной стоимости предпочтение отдаётся более короткому маршруту; при равенстве маршрутов — стабильному порядку SupplierId.
- После выбора используется существующий транзакционный путь оформления заказа: повторно проверяются остаток, маршрутные параметры и баланс, затем списываются деньги и резервируется товар.
- Метод возвращает SupplierId выбранного поставщика и рассчитанную сумму.

## Ограничения и честная оценка
- Это автоматический выбор для закупок сырья производственными площадками через `SupplyLogisticsSystem`, а не для розничного пополнения магазинов через `CityEconomySystem`.
- В стандартном каталоге часть товаров сейчас представлена только у одного поставщика. Выбор между несколькими предложениями заработает для товаров, которые есть у нескольких поставщиков; архитектура метода это поддерживает.
- Текущий критерий — полная цена с доставкой, наличие товара, доступность дороги и платёжеспособность. Рейтинг качества/надёжности из розничных 30-дневных снимков не применяется: он привязан к конкретному магазину и не является общей статистикой поставщика сырья.
- Срок доставки в текущей модели определяется расстоянием после оформления; он пока не участвует в ранжировании. При равной полной цене используется длина маршрута.
- Метод добавлен как API системы логистики; существующий UI заказа не переключён на автоматический выбор и прежние вызовы `TryPlaceOrder` не изменены.
- Unity Editor, компиляция C# и Play Mode в этой среде не запускались.
