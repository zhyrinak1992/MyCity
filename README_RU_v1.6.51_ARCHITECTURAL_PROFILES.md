# My City v1.6.51 — архитектурные профили зданий

## Что добавлено
- Разные визуальные профили для обычного жилья, коттеджей, многоквартирных домов и торговых зданий.
- Разные профили складов: распределительный центр, оптовая база, промышленный склад и топливное хранилище.
- Элементы фасада, балконы, витрины, маркизы, складские доки, вентиляция, трубы и специализированные надстройки появляются по мере модернизации.
- Профиль определяется по уже сохраняемому имени здания (`BuildingRecord.DefinitionId`); формат сохранения и стабильные ID не менялись.
- Общая эволюция уровней 2–15 сохранена и продолжает применяться поверх специализированного профиля.

## Ограничения и безопасность
- Геометрия создаётся процедурно из примитивов; это этап прототипирования, не финальные художественные модели.
- Визуальные элементы не меняют footprint, точки входа, дорожную/пешеходную сеть, вместимость или экономику.
- Для старых сохранений профиль определяется по `DefinitionId`/имени, поэтому отдельная миграция схемы не нужна.
- Реальную компиляцию Unity Editor, Play Mode и iOS build в этой среде выполнить не удалось; необходима проверка в Unity.
