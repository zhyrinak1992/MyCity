# My City — v1.6.47 CITY MAINTENANCE PROJECTS

## Что добавлено
- Сохраняемая модель ремонтного проекта `CityMaintenanceProjectRecord`.
- Связь обращения мэру с проектом через `MayorRequestRecord.ProjectId`.
- Одобренные обращения категорий «Ремонт», «Инфраструктура» и «Благоустройство» создают проект, если в городе есть хотя бы одно здание.
- Перед одобрением игрок выбирает объект ремонта в панели приёмной мэра.
- Проект проходит стадии «В очереди» → «Выполняется» → «Завершён» за три игровых дня.
- Прогресс, сроки, бюджет, целевое здание и факт применения результата сохраняются в `CitySaveData`.
- Повторная обработка одного обращения не создаёт второй проект: используется стабильный ID `maintenance-<requestId>` и `ProjectId`.
- По завершении состояние выбранного здания устанавливается в 100%; значение сохраняется через существующую модель `PlacedBuilding` / `BuildingRecord`.

## Ограничения прототипа
- Проект пока является упрощённой ремонтной задачей: нет бригад, материалов, закупки стройматериалов, погодных задержек или отдельных этапов сметы.
- Текущая модель зданий не содержит визуального повреждения и регулярного износа; поэтому ремонт завершает задачу и гарантирует Condition=100%, но на стандартном новом здании это значение может визуально не отличаться.
- Выбор объекта ремонта доступен среди уже размещённых зданий. Обращения о дорогах и уличном освещении пока привязаны к выбранному зданию, поскольку отдельной модели объектов уличной инфраструктуры ещё нет.
- Бюджет списывается при одобрении обращения и отражается в городском финансовом журнале. Проект не списывает деньги повторно.
- Улучшение уровня здания и визуальное изменение модели здания в этой версии не реализованы.
- Unity Editor compilation, Play Mode и iOS build в этой среде не запускались.
