# My City v1.6.82 — роли участников домохозяйства

## Добавлено
- `HouseholdMemberRecord`: CitizenId, Role, GuardianCitizenId.
- Самый старший совершеннолетний участник становится ответственным взрослым; равенство разрешается по ID.
- Несовершеннолетние связываются с ответственным взрослым как с игровым опекуном.
- Остальные взрослые получают нейтральную роль другого взрослого участника.
- Если взрослых нет, опекун не выдумывается.
- Роли пересобираются из авторитетных записей жителей при загрузке и сохранении.

## Ограничения
Роли описывают ответственность внутри совместного проживания и не утверждают брак, биологическое родство или юридическую опеку. Для этого нужна отдельная генеалогическая система.

Unity-компиляция, Play Mode и iOS-сборка не выполнялись.
